四种受控源

输出由电路里另一处的电压或电流决定：E、G、H、F 各管什么，在 lcapy 里怎么写？

1受控源是什么

独立源的值是写死的：一节 5 V 的电池，接什么都是 5 V。受控源（也叫非独立源）的值则由电路里另一处的电压或电流决定。它像一个两端口元件：一边是“控制端”，只负责感知一个量；另一边是“输出端”，按比例吐出一个电压或电流。

控制量可以是电压或电流，输出量也可以是电压或电流，两两组合正好四种：

\[\begin{aligned} &\text{E：压控电压源 VCVS} & v_o &= K\, v_c \\ &\text{G：压控电流源 VCCS} & i_o &= G_m\, v_c \\ &\text{H：流控电压源 CCVS} & v_o &= R_m\, i_c \\ &\text{F：流控电流源 CCCS} & i_o &= \beta\, i_c \end{aligned}\]

增益的单位跟着“输出 ÷ 控制”走：K 和 β 没有单位，\(G_m\) 是电流除以电压，单位西门子（S），叫跨导；\(R_m\) 是电压除以电流，单位欧姆，叫跨阻。它们是建模的积木：晶体管的小信号模型里，BJT 的集电极电流 ≈ β × 基极电流（F），MOSFET 的漏极电流 ≈ \(g_m\) × 栅源电压（G）；理想运放可以看成增益极大的 E。

Lcapy 中设置受控源非常直观，它沿用了 SPICE 的经典语法，支持所有四种基本类型的线性受控源，元件名的首字母就是上面的 E、G、H、F。

最值得拖的是负载：，输出电压纹丝不动，变的只有电流；，正好反过来。

2E：压控电压源（VCVS）

它的电压由电路中另外两点的电压差控制。

语法：E<name> n+ n- nc+ nc- K

  • E<name>：元件名称，例如 E1。
  • n+ n-：受控源自身的正负节点。
  • nc+ nc-：控制电压的参考正负节点。
  • K：电压增益（无单位）。
  • 关系式：V(n+, n-) = K * V(nc+, nc-)

假设我们要建立一个电压放大器模型，其输出电压是输入电压的 5 倍：

from lcapy import Circuit

# 定义电路
# V1 是输入电压源
# R1 是输入电阻
# E1 是压控电压源，它的电压由节点1和0之间的电压（即V1的电压）控制
# R2 是输出负载
cct_vcvs = Circuit("""
V1 1 0 {u(t)}; down
W 1 1b; right
R1 1b 0_1 1k; down
W 0 0_1; right
E1 2 0_2 1 0 5; down, l=A_v=5
W 0_1 0_2; right=2
W 2 3; right
R2 3 0_3 1k; down
W 0_2 0_3; right
""")

# 绘制电路图（需要本机有 LaTeX 和 circuitikz）
cct_vcvs.draw(style='american')

# 求解节点2的电压 V_out
V_out = cct_vcvs[2].v
print(f"压控电压源 (VCVS) 的输出电压 V(2): {V_out}")
# 结果: 5*Heaviside(t)，即 V(2) = 5 * V(1) = 5 * u(t)

lcapy 解出来的是符号表达式，\(u(t)\) 打印出来是 sympy 的 Heaviside(t)，即单位阶跃。网表每行分号后面那段（down、right=2、l=…）只是画图用的位置和标签，不影响计算；0_1、0_2 这些是画在不同位置的接地点，用导线 W 连回 0。

3G：压控电流源（VCCS）

它产生的电流由电路中另外两点的电压差控制。

语法：G<name> n+ n- nc+ nc- Gm

  • G<name>：元件名称，例如 G1。
  • n+ n-：输出电流的两个端点（方向见第 7 节，lcapy 和 SPICE 在这里不一样）。
  • nc+ nc-：控制电压的参考正负节点。
  • Gm：跨导增益（单位是西门子 S）。
  • 关系式：I = Gm * V(nc+, nc-)

输出电流全部流过负载 R1：

from lcapy import Circuit

# 定义电路
# V1 是输入电压
# G1 是压控电流源，其电流由节点1和0之间的电压控制
# R1 是输出负载，G1产生的电流流过它
cct_vccs = Circuit("""
V1 1 0 {u(t)}; down
G1 2 0_2 1 0 0.1; down, l^=G_m=0.1
W 0 0_2; right=2
W 2 3; right
R1 3 0_3 50; down
W 0_2 0_3; right
""")

cct_vccs.draw(style='american')

# 求解流过电阻R1的电流 I_R1
I_R1 = cct_vccs.R1.i
print(f"压控电流源 (VCCS) 产生的电流 I(R1): {I_R1}")
# 结果: Heaviside(t)/10，即 I(R1) = 0.1 * V(1) = 0.1 * u(t)

注意受控源的输出节点 2 不能和控制节点 1 直接连在一起：节点 1 被理想电压源 V1 钉死在 \(u(t)\)，要是用导线把 2 也接上去，R1 两端的电压就永远是 V1 的电压，电流变成 \(u(t)/50\)，跟 G1 一点关系都没有了。

4H：流控电压源（CCVS）

它的电压由流过另一个元件的电流控制。

关键点：Lcapy 需要一个“电流传感器”来确定控制电流。通常我们会把一个 0 V 的电压源（dummy voltage source）串联在需要测量电流的支路中，然后用这个 0 V 电压源的名称来指定控制电流。

为什么偏偏是电压源？lcapy 和 SPICE 解电路用的都是改进节点分析（MNA）：未知量是各节点的电压，外加每个电压源上的电流。普通电阻上的电流不是方程里的未知量，电压源上的才是。一个 0 V 的电压源两端没有压降，接进去不改变电路，却让这条支路的电流成了一个有名字、能被引用的量。

语法：H<name> n+ n- V_sensor Rm

  • H<name>：元件名称，例如 H1。
  • n+ n-：受控源自身的正负节点。
  • V_sensor：作为电流传感器的 0 V 电压源的名称。
  • Rm：跨阻增益（单位是欧姆 Ω）。
  • 关系式：V(n+, n-) = Rm * I(V_sensor)

from lcapy import Circuit

# 定义电路
# Vsense 是一个0V的电压源，作为电流传感器，用于“感知”流过 R1 的电流
# H1 是流控电压源，它的电压由流过 Vsense 的电流控制
cct_ccvs = Circuit("""
I1 1 0 {u(t)}; down
R1 1 a 100; right
Vsense a 0_a 0; down
W 0 0_a; right
H1 2 0_2 Vsense 50; down, l=R_m=50
W 0_a 0_2; right=2
W 2 3; right
R2 3 0_3 1k; down
W 0_2 0_3; right
""")

cct_ccvs.draw(style='american')

# 求解节点2的电压 V_out
V_out = cct_ccvs[2].v
print(f"流控电压源 (CCVS) 的输出电压 V(2): {V_out}")
# 结果: 50*Heaviside(t)。I(Vsense) = I1 = u(t)，所以 V(2) = 50 * I(Vsense) = 50 * u(t)

5F：流控电流源（CCCS）

它产生的电流由流过另一个元件的电流控制。和 CCVS 一样，它也需要一个 0 V 电压源作为电流传感器。

语法：F<name> n+ n- V_sensor Beta

  • F<name>：元件名称，例如 F1。
  • n+ n-：输出电流的两个端点（方向见第 7 节）。
  • V_sensor：作为电流传感器的 0 V 电压源的名称。
  • Beta：电流增益（无单位），通常用于 BJT 等模型。
  • 关系式：I = Beta * I(V_sensor)

下面是一个 BJT 的简化模型：基极电流 \(I_b\) 由 V1 经 R_B 提供，集电极电流 \(I_c = \beta I_b\) 从电源 V_CC 经负载 R_L 流进 F1。

from lcapy import Circuit

# 定义电路
# V1 是基极驱动
# Vsense 用于感知基极电流 I_b
# F1 是流控电流源，模拟集电极电流 I_c = Beta * I_b = 100 * I_b
# R_L 是集电极负载电阻，V_CC 是电源
# （注释别写在网表行尾：lcapy 会把 # 后面的字当成画图参数的一部分）
cct_cccs = Circuit("""
V1 1 0 {u(t)}; down
R_B 1 a 1k; right
Vsense a 0_a 0; down
W 0 0_a; right
F1 c 0_c Vsense 100; down, l^=\\beta=100
W 0_a 0_c; right=2
R_L d c 500; down
W d e; right
V_CC e 0_e 10; down
W 0_c 0_e; right
""")

cct_cccs.draw(style='american')

# 集电极电流就是从 V_CC 经 R_L 流进 F1 的电流
I_c = cct_cccs.R_L.i
print(f"流控电流源 (CCCS) 产生的电流 I_c: {I_c}")
# 结果: Heaviside(t)/10。I_b = V1 / R_B = u(t)/1000，所以 I_c = 100 * I_b = 0.1 * u(t)

集电极节点 c 的电压是 \(10 - 0.1u(t)\times 500 = 10 - 50u(t)\)：理想的 F 不管电压，硬是把 0.1 A 拉过 R_L，节点电压可以掉到负几十伏。真实的晶体管在这之前早就饱和了，这正是“理想受控源”和真器件的区别。

6总结

类型元件描述控制量输出量语法
VCVSE压控电压源电压 V(nc+, nc-)电压E name n+ n- nc+ nc- K
VCCSG压控电流源电压 V(nc+, nc-)电流G name n+ n- nc+ nc- Gm
CCVSH流控电压源电流 I(V_sensor)电压H name n+ n- V_sensor Rm
CCCSF流控电流源电流 I(V_sensor)电流F name n+ n- V_sensor Beta

最重要的技巧：当你需要用电流作为控制量时（CCVS 和 CCCS），记得在被控制的支路中串联一个值为 0 的电压源，并用它的名字来告诉 Lcapy 你要测量哪里的电流。

7电流往哪个方向流

正负号是受控源最容易错的地方。SPICE 的约定是：电流源（I、G、F）的正电流从 n+ 进去、穿过源、从 n− 出来；电压源上的电流也是从 n+ 穿过源流到 n−。lcapy 1.26 实测下来不完全一样：

网表lcapy 1.26 的结果和 SPICE 比
I1 1 0 2
R1 1 0 3		V(1) = +6 V：电流从 n+ 推出到外电路相反（SPICE 是 −6 V）
G1 2 0 1 0 0.1
R1 2 0 50		V(2) = +5u(t)：同样从 n+ 推出相反
F1 2 0 Vsense 100
R_L 2 0 500		V(2) = −50u(t)：电流从 n+ 吸进去相同
Vsense a 0 0控制电流以从 a 穿过 Vsense 流到 0 为正相同

（F 那一行的 Vsense 电流是 +1 mA，接法和第 5 节一样。）所以第 4 节 CCVS 的电流源写成 I1 1 0：要是按 SPICE 的习惯写成 I1 0 1，lcapy 算出来的是 \(-50u(t)\)。稳妥的做法是写完先接一个简单负载，看一眼正负号对不对。

另外三个 lcapy 的小坑：

  • 网表行尾别写 # 注释。lcapy 不会把它当注释，而是当成画图参数的一部分：Vsense a 0 0; down # 传感器 解析出来的方向是 “down # 传感器”，画图时就乱了。注释写在 Python 那边。
  • 画图提示要前后一致。同一对节点之间不能一个元件说 down、另一个说 right，否则 draw() 报 “schematic graph has a loop”。并联的元件各用一个接地点（0_1、0_2…），再用导线连回 0。画图还需要本机装好 LaTeX 和 circuitikz。
  • F1.i 取不到。lcapy 1.26 里对 F 元件取电流会报 KeyError，第 5 节因此改用串在同一条支路上的 R_L.i。
