\(a^n u[n]\) 的 z 变换为什么是这个分式，它在哪里才算数。

能动的：拖 探针 z、极点 a　拖动画面转着看　点文中的 放进图里

问题：\(a^n u[n]\) 的 z 变换，为什么算出来是这个分式？

0起点：z 变换的定义

把 \(x[n] = a^n u[n]\) 代入定义（\(u[n]\) 保证只有 \(n\ge 0\) 的项）：

\[X(z) = \sum_{n=0}^{\infty} a^n z^{-n}\]

按幂次展开写出来：

\[X(z) = \underbrace{1}_{n=0} + \underbrace{\frac{a}{z}}_{n=1} + \underbrace{\frac{a^2}{z^2}}_{n=2} + \underbrace{\frac{a^3}{z^3}}_{n=3} + \cdots\]

1第一步：认出这是"等比级数"（geometric series）

每一项都是前一项乘上同一个数：

\[\frac{a^2/z^2}{a/z} = \frac{a}{z}, \qquad \frac{a^3/z^3}{a^2/z^2} = \frac{a}{z}, \qquad \cdots\]

公比恒为

\[q = \frac{a}{z}\]

所以级数就是

\[X(z) = \sum_{n=0}^{\infty} q^n = 1 + q + q^2 + q^3 + \cdots\]

接下来唯一的问题：这个无穷加和等于多少？ 这由等比级数求和公式回答，下面不背公式，现场推。

2第二步：等比级数求和公式的证明

2.1 先算"有限项"的部分和

设前 \(N+1\) 项的和为

\[S_N = 1 + q + q^2 + \cdots + q^N\]

错位相减技巧：两边乘 \(q\)

\[q\,S_N = q + q^2 + \cdots + q^N + q^{N+1}\]

两式相减（中间的项全部对消，只剩头尾）：

\[S_N - q\,S_N = 1 - q^{N+1}\]

左边提出 \(S_N\)：

\[S_N\,(1-q) = 1 - q^{N+1} \qquad\Longrightarrow\qquad S_N = \frac{1-q^{N+1}}{1-q}\]

2.2 数值验证一下（\(q = \tfrac12\)）

\(1 + \tfrac12 + \tfrac14 + \cdots + \tfrac1{2^N} = \dfrac{1-(1/2)^{N+1}}{1-1/2} = 2\left(1-\left(\tfrac12\right)^{N+1}\right)\)

  • \(N=2\)：\(1+\tfrac12+\tfrac14 = 1.75\)，公式给 \(2(1-\tfrac18) = 1.75\) ✓
  • \(N\) 越大越接近 2

2.3 让 \(N \to \infty\)：收敛条件出现了

\[S_N = \frac{1-q^{N+1}}{1-q} \xrightarrow{\;N\to\infty\;} \frac{1}{1-q} \quad\Longleftrightarrow\quad q^{N+1} \to 0\]

而 \(q^{N+1}\to 0\) 当且仅当 \(|q| < 1\)（这就是"衰减打赢生长"的条件）：

\[\boxed{\;\sum_{n=0}^{\infty} q^n = \frac{1}{1-q}, \qquad \text{条件: } |q|<1\;}\]

若 \(|q|\ge 1\)：\(q^{N+1}\) 不趋于零，部分和没有极限 ⟹ 级数发散，公式无效。

3第三步：把 \(q = a/z\) 代回去

\[X(z) = \frac{1}{1-q} = \frac{1}{1-\dfrac{a}{z}}\]

用 \(z^{-1} = \dfrac{1}{z}\)（这只是记号，\(z^{-1}\) 的定义就是 \(1/z\)）：

\[\frac{1}{1-\dfrac{a}{z}} = \frac{1}{1-az^{-1}}\]

同时把收敛条件翻译成 z 的语言：

\[|q| < 1 \iff \left|\frac{a}{z}\right| < 1 \iff \frac{|a|}{|z|} < 1 \iff |z| > |a|\]

\[\boxed{\;a^n u[n] \;\xleftrightarrow{\;\mathcal{Z}\;}\; \dfrac{1}{1-az^{-1}}, \qquad |z|>|a|\;}\]

4终检：代具体数字验证全链路

取 \(a = 0.5,\; z = 2\)（满足 \(|z|>|a|\) ✓）：

按定义逐项加：

\[1 + \frac{0.5}{2} + \left(\frac{0.5}{2}\right)^2 + \cdots = 1 + 0.25 + 0.0625 + \cdots = \frac{1}{1-0.25} = \frac{4}{3} \approx 1.333\]

按闭式算：

\[\frac{1}{1-0.5\cdot 2^{-1}} = \frac{1}{1-0.25} = \frac43 \quad ✓\]

取 \(z = 0.4\)（ROC 之外）：级数变成 \(1 + 1.25 + 1.5625 + \cdots\)，爆炸；闭式给 \(\frac{1}{1-1.25} = -4\)，闭式在那里不代表级数——这就是为什么必须写 ROC。

5和你第 4 章会的东西对上号

第 4 章算 DTFT 时你干过同一件事：

\[X(e^{j\omega}) = \sum_{n=0}^{\infty} \left(a e^{-j\omega}\right)^n = \frac{1}{1-ae^{-j\omega}}, \qquad |a|<1\]

对比：

第 4 章 (DTFT) 第 5 章 (z 变换)
级数 \(\sum (ae^{-j\omega})^n\) \(\sum (a/z)^n\)
公比 \(q = ae^{-j\omega}\)，\(|q|=|a|\) 锁死 \(q = a/z\)，|q| 可调
收敛条件 \(|a|<1\)（不满足就废） \(|z|>|a|\)（写进答案 = ROC）
结果 \(\dfrac{1}{1-ae^{-j\omega}}\) \(\dfrac{1}{1-az^{-1}}\)

同一个求和技巧，z 版多了个可调的 \(r\)，收敛条件从"死门槛"变成"答案的一半"。

6三个常见疑问

Q1：为什么 \(z^{-1}\) 就是 \(1/z\)？ 负指数的定义：\(z^{-1} \equiv \dfrac{1}{z}\)，\(z^{-n} = \left(\dfrac1z\right)^n\)。纯记号约定。

Q2：为什么要 \(|q|<1\)，\(|q|=1\) 不行吗？ \(|q|=1\) 时 \(q^{N+1}\) 永远在单位圆上打转不趋于零，部分和无极限（如 \(\sum 1^n = 1+1+1+\cdots\)）。收敛必要条件是通项 \(\to 0\)。

Q3：这个分式和极点什么关系？ \[\frac{1}{1-az^{-1}} = \frac{z}{z-a}\] 分母为零的点 \(z = a\) 就是极点——级数的公比在此处等于 1，发散，所以极点必在 ROC 边界上。

总结（一条链）

\[a^n u[n] \;\to\; \sum_{n\ge0} a^n z^{-n} \;\to\; \text{认出公比 } q=\tfrac az \;\to\; \text{错位相减证 } \sum q^n = \tfrac{1}{1-q} \;\to\; \text{条件 } |q|<1 \Rightarrow |z|>|a|\]

一句话：\(\dfrac{1}{1-az^{-1}}\) 就是等比级数求和公式 \(\dfrac{1}{1-q}\) 代入 \(q = a/z\) 的结果；ROC \(|z|>|a|\) 就是 \(|q|<1\) 翻译成 z 的语言。
