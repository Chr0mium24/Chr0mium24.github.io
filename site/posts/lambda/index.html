Lambda初窥

只用函数写数字：n 就是“把 f 用 n 次”。

能动的：换 运算　调 m、n　点代码里的 定义　点文中的 试试

1原文

点任意一行定义，图就切到那个运算。

ZERO = lambda f:lambda x:xSUC = lambda church:lambda f:lambda x:church(f)(f(x)) to_int = lambda n:n(lambda x:x+1)(0)to_church = lambda n:ZERO if n==0 else SUC(to_church(n-1)) ONE = to_church(1)TWO = to_church(2)THREE = to_church(3) ADD = lambda m:lambda n:lambda f:lambda x:m(f)(n(f)(x))ADD_1 = lambda m:lambda n:m(SUC)(n)MUL = lambda m:lambda n:lambda f:lambda x:m(lambda x1:n(f)(x1))(x)POW = lambda m:lambda n:n(MUL(m))(ONE) #POW(m)(n) = m^n PAIR = lambda x:lambda y:lambda f:f(x)(y)FST = lambda p: p(lambda x: lambda y: x)LST = lambda p: p(lambda x: lambda y: y)PHI = lambda p: PAIR(LST(p))(SUC(LST(p)))PRED = lambda n:FST(n(PHI)(PAIR(ZERO)(ZERO)))SUB = lambda m: lambda n: n(PRED)(m) IS_ZERO = lambda n:n(lambda x:FALSE)(TRUE)LTE = lambda m:lambda n:IS_ZERO(SUB(m)(n))GT = lambda m:lambda n:NOT(LTE(m)(n))EQ = lambda m:lambda n:AND(LTE(m)(n))(LTE(n)(m)) I = lambda x:xW = lambda f:lambda x:f(x)(x)

2数字 = 用几次

ZERO 一次 f 都不用，直接把 x 还回去；SUC 先按原来的次数用 f，再多用一次。所以 THREE 展开就是 f(f(f(x)))，to_int 只是拿“加一”当 f、拿 0 当 x，数一数用了几次。

3加法是接着用，乘法是一份一份用

ADD 先让 n 用 n 次 f，再把结果交给 m 接着用 m 次。

MUL 把“用 n 次 f”整个当成一个新的 f，再让 m 用它 m 次。POW 则是从 ONE 出发，连乘 n 次 m。

4最难的是减一

Church 数只会“往前用”，没法撤回一次 f。PRED 的办法是拿一对数 (前一个, 当前) 从 (0, 0) 出发，每步变成 (当前, 当前+1)，走 n 步以后取前一个，就是 n−1。SUB 再把 PRED 用 n 次；减过头会停在 0。
