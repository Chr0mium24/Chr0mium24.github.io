Lambda 初窥

只用函数，能不能写出数字、加减乘除和递归？

λ 演算是 Alonzo Church 在 1930 年代提出的计算模型，整个语言只有三样东西：

  • 变量：x；
  • 抽象（定义函数）：λx.M，参数 x，函数体 M；
  • 应用（调用函数）：M N，把 N 喂给 M。

计算只有一条规则，叫 β 归约：(λx.M) N 变成“把 M 里的 x 全换成 N”。没有数字，没有 if，没有循环，连多参数函数都没有：两个参数就写成“返回函数的函数”，λf.λx. …，这叫柯里化。

Python 的 lambda 恰好就是 λ，lambda f: lambda x: … 一字不差地对应 λf.λx. …。下面的代码只用 lambda 和调用，把自然数、算术、比较一样样搭出来，最后再看递归怎么来。

完整的一份（补上了比较要用的布尔值）可以直接在浏览器里跑：

ZERO = lambda f:lambda x:x
SUC = lambda church:lambda f:lambda x:church(f)(f(x))
to_int = lambda n:n(lambda x:x+1)(0)
to_church = lambda n:ZERO if n==0 else SUC(to_church(n-1))
ONE, TWO, THREE = to_church(1), to_church(2), to_church(3)

ADD = lambda m:lambda n:lambda f:lambda x:m(f)(n(f)(x))
ADD_1 = lambda m:lambda n:m(SUC)(n)
MUL = lambda m:lambda n:lambda f:lambda x:m(lambda x1:n(f)(x1))(x)
POW = lambda m:lambda n:n(MUL(m))(ONE) #POW(m)(n) = m^n

PAIR = lambda x:lambda y:lambda f:f(x)(y)
FST = lambda p: p(lambda x: lambda y: x)
LST = lambda p: p(lambda x: lambda y: y)
PHI = lambda p: PAIR(LST(p))(SUC(LST(p)))
PRED = lambda n:FST(n(PHI)(PAIR(ZERO)(ZERO)))
SUB = lambda m: lambda n: n(PRED)(m)

# 布尔值：TRUE 选第一个，FALSE 选第二个
TRUE = lambda x: lambda y: x
FALSE = lambda x: lambda y: y
NOT = lambda b: b(FALSE)(TRUE)
AND = lambda p: lambda q: p(q)(p)
OR = lambda p: lambda q: p(p)(q)
to_bool = lambda b: b(True)(False)

IS_ZERO = lambda n:n(lambda x:FALSE)(TRUE)
LTE = lambda m:lambda n:IS_ZERO(SUB(m)(n))
GT = lambda m:lambda n:NOT(LTE(m)(n))
EQ = lambda m:lambda n:AND(LTE(m)(n))(LTE(n)(m))
GTE = lambda m:lambda n:OR(GT(m)(n))(EQ(m)(n))
LT = lambda m:lambda n:NOT(GTE(m)(n))

print("3 + 2 =", to_int(ADD(THREE)(TWO)), to_int(ADD_1(THREE)(TWO)))
print("3 × 2 =", to_int(MUL(THREE)(TWO)), "  2 ** 3 =", to_int(POW(TWO)(THREE)))
print("PRED(3) =", to_int(PRED(THREE)), "  2 - 3 =", to_int(SUB(TWO)(THREE)))
print("2 <= 3:", to_bool(LTE(TWO)(THREE)), "  2 == 2:", to_bool(EQ(TWO)(TWO)), "  3 < 2:", to_bool(LT(THREE)(TWO)))

2数字 = 用几次

Church 数的定义是：n 就是“接受 f 和 x，把 f 作用在 x 上 n 次”的函数，n = λf.λx. f(f(…f(x)…))。

ZERO 一次 f 都不用，直接把 x 还回去；SUC 先按原来的次数用 f，再多用一次。所以 THREE 展开就是 f(f(f(x)))，to_int 只是拿“加一”当 f、拿 0 当 x，数一数用了几次。

3加法是接着用，乘法是一份一份用

ADD 先让 n 用 n 次 f，再把结果交给 m 接着用 m 次。ADD_1 是另一种写法：把 SUC 当成 f，在 n 的基础上加一加 m 次，结果一样。

MUL 把“用 n 次 f”整个当成一个新的 f，再让 m 用它 m 次。POW 则是从 ONE 出发，连乘 n 次 m。

注意这里一个“数”从头到尾都只是函数：MUL(THREE)(TWO) 的结果仍然是 λf.λx. …，只有最后 to_int 的时候才变回 Python 的整数。

4最难的是减一

Church 数只会“往前用”，没法撤回一次 f。PRED 的办法是拿一对数 (前一个, 当前) 从 (0, 0) 出发，每步变成 (当前, 当前+1)，走 n 步以后取前一个，就是 n−1。

“一对数”本身也是函数：PAIR(x)(y) 是一个等着别人传“选择器”进来的函数，FST 传进“选第一个”，LST 传进“选第二个”。PHI 就是那一步 (a, b) → (b, b+1)。

SUB(m)(n) 再把 PRED 用 n 次；减过头会停在 0，因为 PRED(ZERO) 还是 ZERO。

5真假和比较

布尔值也是“选择”：TRUE = λx.λy. x 选第一个，FALSE = λx.λy. y 选第二个。这样 b(甲)(乙) 本身就是 if-else，NOT、AND、OR 都能用选择写出来，比如 AND = λp.λq. p(q)(p)：p 为真就看 q，p 为假就直接是 p。

IS_ZERO = n(λx. FALSE)(TRUE)：从 TRUE 出发，把“不管什么都变成 FALSE”的函数用 n 次。只要用过一次就是 FALSE，一次都没用（n 是 0）才还是 TRUE。

有了它，比较全都能借减法写：因为减过头会停在 0，m − n = 0 恰好等价于 m ≤ n，所以 LTE = IS_ZERO(SUB(m)(n))；两边都 ≤ 就是相等，EQ = AND(LTE(m)(n))(LTE(n)(m))；剩下的 GT、GTE、LT 用 NOT、OR 拼。

6递归从哪来

λ 演算里的函数没有名字，函数体里没法直接调用“自己”。办法是让函数把自己当参数传下去。代码最后那个 W = λf.λx. f(x)(x) 做的就是关键的一步：把同一个参数用两次。把“自己应用自己”再包一层，就得到 Y 组合子：

Y = λf. (λx. f(x x)) (λx. f(x x))

它满足 Y g = g (Y g)：g 拿到的参数正好是“g 的不动点”，也就是递归调用自己的那个函数。但直接搬进 Python 会停不下来：Python 先算参数再调用，x(x) 会被立刻展开，展开出来又是 x(x)……一直到栈溢出。改法是把 x(x) 包进 lambda v: x(x)(v)，用到的时候才展开，这个版本叫 Z 组合子：

W = lambda f:lambda x:f(x)(x)            # 同一个参数喂两次
print(W(lambda a: lambda b: a * b)(7))   # 7 * 7

fact_step = lambda self: lambda n: 1 if n == 0 else n * self(n - 1)

# Y 组合子：λf.(λx.f(x x))(λx.f(x x))
Y = lambda f: (lambda x: f(x(x)))(lambda x: f(x(x)))
try:
    Y(fact_step)
except RecursionError as e:
    print("Y：", e)

# Z 组合子：把 x(x) 包进 lambda v: …，用到时才展开
Z = lambda f: (lambda x: f(lambda v: x(x)(v)))(lambda x: f(lambda v: x(x)(v)))
fact = Z(fact_step)
print("Z：5! =", fact(5))
